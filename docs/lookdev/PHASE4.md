## E-2 影の階調を AO テクスチャで作る

### E-2a 参考画像の検証 → 壁際の勾配は無い。目標値 0.26 は無効

建物の足元から街路へ向かう直線 5 本、各 45 点（3×3 中央値）の輝度プロファイル
（`e2a_reference_profile_lines.png` に線の位置、`e2a_reference_profiles.png` にグラフ）。

- **L4（右の建物の足元 → 路面、全長が影の中）**: 始点 29、終点 30、途中は 16〜29 を交互に振れる（路面テクスチャの暗い粒）。
  **壁際から離れても明るくならない。勾配は無い。**
- L1 / L2（大きな建物の足元 → 路面）: 足元 9〜10 の直後に 68〜107 の日向へ跳び、その先で 47 と 103 が交互に現れる。
  つまり**大きな建物の足元の路面は日向**で、影は足元に接していない。
- L3・L5 は白線（206〜224）を横切るので端で跳ぶ。

読み取り: 参考画像の「芯 ≈11」と「開けた影 ≈30」は同じ影の中の連続的な勾配ではなく、
**別の領域**（画面右下の一段暗い区域と、路面の暗い粒）である。空の遮蔽なら壁際が暗く離れると明るいはずだが、
L4 はその逆にも順にもなっていない。**「開けた影 = 0.26」を AO で作るという前提は無効。**
なお L1/L2 の結果は、大きな建物の足元に日が当たっている、すなわち参考画像の太陽が
建物のカメラ側（順光寄り）にあることも示している。画面の大きな影はさらに手前の建物が落としている。

### E-2b 実装

Godot 4.7 の `StandardMaterial3D` に `ao_enabled` / `ao_texture` / `ao_on_uv2` / `ao_light_affect` / `ao_texture_channel`
があることを実機で確認した（`ao_light_affect` 既定 0.0 = 環境光にのみ効く）。

- 地面と建物 4 面を UV2 付きの板（SurfaceTool）で作り直し、起動時にスクリプトで AO を焼く:
  半球のコサイン重みサンプル 24 本（Hammersley 列、決定的）、**レイ距離 18 m**（建物高さの 2〜3 倍）、
  遮蔽物は建物 AABB と地面。地面は 2 texel/m で焼き、表示時にバイリニアで 4 倍。0.6 秒で終わる。
- `ao_on_uv2 = true`、`ao_light_affect = 0.0` を明示、`ao_texture_channel = RED`。
- `ao_debug=1` で AO だけを白地に表示できる。

### E-2c 較正 → 分離は 13% しか無く、目標は幾何的に成立しない

点は前フェーズと同じ P_sun (−5, 0, −1)、P_open (2, 0, −2)、P_core (−1, 0, −3) と路面端 (0, 0, −3.4)。
焼き込み AO の値: P_sun 0.71、P_open 0.67、P_core 0.58、路面端 0.54。
**7 m 幅の街路・7 m の建物では、路面のどこでも空の 3 割前後が建物に隠れ、壁から 3 m と 4 m の差は 13%** しかない。
`e2c_ao_sweep.json`。

| 設定 | P_sun | P_open 比 | P_core 比 | 路面端 比 |
| --- | --- | --- | --- | --- |
| AO なし、ambient ×1.0（0.234） | 110.4 | 0.116 | 0.129 | 0.120 |
| AO、ambient ×1.0 | 109.9 | 0.075 | 0.074 | 0.068 |
| AO、ambient ×1.6 | 110.8 | 0.117 | 0.115 | 0.107 |
| **AO、ambient ×1.65（0.386、採用）** | **110.8** | **0.121** | **0.118** | **0.109** |
| AO、ambient ×2.9（依頼の想定） | 112.5 | 0.188 | 0.182 | 0.172 |
| AO、ambient ×1.6、ao_power 2 | 110.1 | 0.077 | 0.064 | 0.059 |
| AO、ambient ×1.6、ao_power 5 | 109.0 | 0.020 | 0.010 | 0.010 |
| AO、ambient ×1.6、レイ 10 m | 111.0 | 0.135 | 0.141 | 0.122 |

- ambient を上げると open と core が同じ比率で上がる。ao_power を上げると両方が同じ比率で下がる。
  **open 0.26 と core 0.12 を同時に作るには ao_power ≈ 6 と ambient ×20 が要り、物理的な意味を失う。**
- 想定された副作用の確認: ao_power 8 でも P_sun は 110.8 → 108.6（−2.2）。**`ao_light_affect = 0` は効いている**
  （日向は環境光の寄与分しか動かない。許容 2.5 以内）。
- 採用は **AO ON + ambient 0.386**。P_core/P_sun 0.118（目標 0.120 維持）。AO は建物の足元 1 m の暗まりとして
  残す（物理的に妥当で害が無い）。「開けた影」の目標は E-2a のとおり無効なので追わない。

## E-3 スプライトのスケール変動

### E-3a 参考画像

主人公スプライト周辺を x8（`e3a_reference_sprite_x8.png`）。**行の間引きは見えない。** 輪郭の太さは全行で一定、
ドットは均一な 2×2（= 632 描画時の 1 px）。少なくとも画面中央付近では 1 texel = 1 px で描かれている。
奥行きが変わったときの挙動は 1 枚からは判定できない。

### E-3b 実測

28×56 texel（1×2 m）のテストスプライト（上半分は 1 texel おきの横縞、下半分は 2 texel の市松、白い輪郭）を
(−13, 0, 0.5) → (2, 0, 0.5) へ 90 フレームで等速に歩かせた。見かけの高さは 50.4 → 64.0 px（0.90〜1.14 倍）。
`e3b_walk_sprite_x6.png`（奥・中・手前の x6）、`e3b_walk_mad.png`、`video/E3_*_1x.gif` / `_3x.gif` / `_sprite_x6.gif`。

| 条件 | 見かけの高さ | x6 での見え方 | スプライト画素 MAD（平均 / 最大） |
| --- | --- | --- | --- |
| A Nearest（現状） | 50.4〜64.0 px | 縞の太さが不規則。奥で行が欠け、手前で行が重複。歩くと入れ替わる | 38.4 / 83 |
| B 線形 + ミップマップ | 50.4〜64.0 px | 縞が桃色に滲み、市松が灰白に溶ける。1:1 の位置でも滲む | 24.2 / 54 |
| C 整数 texel 比にスナップ | **56.0 px 一定** | 全距離で縞・市松が完全に整う。大小の変化は無くなる | 44.1 / 83 |
| D C + 位置を整数 px にスナップ | 56.0 px 一定 | C と同じ。動きが 1 px 単位の段になる | 48.9 / 83 |

縞の行の乱れを直接数えた（スプライト中心列の赤/黒ランの長さが中央値と違う割合。`e3b_walk_rows.json`。
検出できたフレームのみ）: **A は 28 フレーム中 27 で行が乱れ、ラン 700 本中 47 本（6.7%）が不揃い。
C は 24 フレーム中 0、D は 27 フレーム中 0。** B は縞が滲んで検出不能（86 フレーム）。

**MAD はこの判定には使えない。** 縞 1 texel のスプライトはサブピクセルの移動で全行が一斉に反転するため、
位置の揺れが数値を支配し、整合が最も良い C/D が A より大きく出る。B が小さいのは滲みで振幅が落ちたから。
判定は x6 の静止画と GIF で行う。数値は参考として残す（`e3b_walk.json`）。

### E-3c 結論

**C を採用する（Nearest + 見かけの texel/px 比を最も近い整数に丸める）。**

- FOV 18° では比が 0.86〜1.14 の範囲に収まり、丸めると常に 1。**スプライトは距離に依らず等倍**で描かれ、
  行の間引きは原理的に起きない。「プチッ」と切り替わる境界（比 1.5）はこの画角では現れない。
  カメラをズームする演出を入れるなら、そこで 1 ↔ 2 倍が切り替わる。
- 代償は、スプライトが奥行きで大小しないこと。背景は透視で縮むので、奥のキャラクターは背景に対して
  相対的に 14% 大きく、手前では 12% 小さく見える。参考画像の主人公が 1:1 で描かれていること（E-3a）と整合する。
- A は却下（間引きが GIF で明確）。B は却下（ドット絵でなくなる）。D は必要な場面だけ（背景は滑らかに動くので、
  スプライトだけ 1 px 刻みにすると相対的な段付きが見える）。
- 素材への影響: **スプライトは 28 texel/m で描き、等倍表示前提で線の太さを決めてよい。** 縮小・拡大への耐性は不要。
