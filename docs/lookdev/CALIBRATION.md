# lookdev 較正フェーズ 2

2026-09-06。[REPORT.md](REPORT.md) の続き。Godot 4.7.2 / Forward+ / RTX 4060 Ti、実機撮影。
較正中の固定条件: **Fog OFF、SDFGI OFF（元から未使用。明示的に無効化）、Glow OFF、街灯 OFF、sun_energy 不変。**
ツール: `tools/lookdev_calib.py`（スイープと点測定）、`tools/measure.py`（面積率・ヒストグラム・色相統計）。

## 前提が一つ崩れていた: 前回の「日向」は街灯の光だった

夕方プリセットは街灯（energy 5、range 11 m）を点けていた。街灯 2 灯で路面の大半が照らされ、
前回「日向 L=110 / 影 L=28.6、比 0.259」と測った「影」は街灯の光が混じった値だった。
街灯を消すと路面はほぼ全域が太陽の影で、全体の中央値は 34 → 12.6 に落ちる。

**したがって A-2 の「影側を 0.34 倍にする」は前提ごと誤りで、実際は逆方向（環境光を上げる）だった。**
夕方プリセットは街灯を点けない設定に変えた（`lamps=1` で点く）。

## A-1 tonemap が反映されていない疑い → 反映はされている。Reinhard が恒等写像だった

確認した項目:

| 確認 | 結果 |
| --- | --- |
| enum 値 | LINEAR=0 REINHARDT=1 FILMIC=2 ACES=3 AGX=4。辞書 `TONEMAPS` はこの値を返す |
| 上書き | `tonemap_mode` を書くのは `_apply_env_toggles()` のみ。`_ready()` → `_apply_all()` の 1 回。他に Environment を触る初期化は無い |
| 撮影タイミング | 設定は `_ready()`（描画前）で適用済み。撮影は 40 フレーム後 |
| 5 モードの画素差 | white=1.0 で linear と reinhard は **SHA-256 が完全一致**（画素差ゼロ）。filmic / aces / agx は異なる |

原因は Godot の Reinhard の式。`tonemap_reinhard(c, white) = c * (1 + c / white²) / (1 + c)` で、
**white = 1.0 のとき恒等写像になる。** `tonemap_white` は Godot 既定も当シーンも 1.0 だった。
Reinhard の統計が linear と 3 桁一致したのはこのため。バグではないが、
white=1.0 のままでは Reinhard の比較は無意味だった。

修正: `white=<f>` 引数を追加し、比較セットに `reinhard white=4` と `filmic white=4` を加えた。
AgX は white を参照しない（white=1 と 4 でハッシュ一致）。

5 モードの SHA-256（ambient ×1.30、街灯 OFF）:

| モード | white=1.0 | white=4.0 |
| --- | --- | --- |
| linear | `9e0c3192afaad1c5…` | `9e0c3192afaad1c5…`（white 無関係） |
| reinhard | `9e0c3192afaad1c5…` **= linear** | `11813769ab428616…` |
| filmic | `ea011f5c8bd925e9…` | `4f312986defa3a26…` |
| aces | `41b31f37b0ced017…` | `ea20c1c5c2704b80…` |
| agx | `f8ef054f2f52b97c…` | `f8ef054f2f52b97c…`（white 無関係） |

white=4.0 では 5 つとも異なる。

同じ 2 点（下記 A-2 の計測点）で測った日向・日陰と、画面全体の p95:

## A-3 日陰面積率と色相統計（`tools/measure.py`）

参考画像で確定した目標値と、現状のベスト設定（下記）のレンダーの値:

| 指標 | 参考画像 | ベスト（街灯 OFF） | 差 |
| --- | --- | --- | --- |
| L p5 / p50 / p95 | 7.8 / 40.5 / 123.5 | 8.6 / 19.9 / 124.0 | 中央値が半分 |
| shadow_fraction L<20 | 0.253 | 0.552 | 暗部が 2.2 倍 |
| shadow_fraction L<40 | 0.494 | 0.763 | |
| shadow_fraction L<60 | 0.714 | 0.838 | |
| 明部（上位 25%）色相 / 彩度 / RGB | 336° / 0.172 / (120,106,109) | 352° / 0.237 / (109,86,87) | やや赤寄り・彩度高め |
| 暗部（下位 25%）色相 / 彩度 / RGB | 229° / 0.432 / (10,11,17) | 242° / 0.539 / (9,9,19) | 色相は一致、彩度やや高い |

ヒストグラム: `hist_ref_vs_best.png`。

読み取り:

- **暖色光 × 寒色影は数値として出ている。** 明部 336〜352°（赤〜マゼンタ寄りの暖色）、
  暗部 229〜242°（青）。方向は参考画像と同じ。
- 暗部の彩度は最初 0.80 あった（環境光 (0.28,0.34,0.62) が青すぎた）。輝度を保って彩度を 0.3 倍に
  した環境光 (0.327,0.345,0.429) に変え、0.54 まで下げた。影比は 0.118 のまま。
- **面積率が違う。** 参考は L<20 が 25% だが、こちらは 55%。参考の暗部の山は L 10〜20 と 30〜40 の
  2 つに割れているのに対し、こちらは L 15 付近に 1 つの鋭い山。
  つまり参考画像の影は**一様ではなく、芯（≈11）と開けた影（≈30）の階調がある。**
  こちらは環境光が一定なので影が全域で芯の明るさになる。
  芯どうしを 0.120 で合わせた結果、影の残り全部が芯と同じ暗さになり、中央値が半分になった。
- 依頼にあった「日向と日陰の面積比が逆」については、L<40 の面積率で見ると参考 0.49 / こちら 0.76 で、
  **こちらの方が日陰が多い**（前回の絵で日向に見えていた部分は街灯の光）。

これは環境光の**値**ではなく**分布**の問題で、単一色の ambient では解けない。候補は
(a) SDFGI（空の遮蔽と建物からの跳ね返りで影に階調が付く。較正中は禁止だったので未評価）、
(b) 半径の大きい SSAO を ambient にのみ効かせる（芯を作る。開けた影を 30 に上げてから AO で芯を 11 に落とす）、
(c) 環境光を「開けた影」基準（比 0.29 前後）に上げ、芯は AO に任せる。
次のフェーズで (b)(c) → (a) の順に試すのがよい。

## A-4 アルベドと光の切り分け

ambient ×1.30 を固定し、壁の基準アルベド（リニア輝度。色相は藍のまま）だけを変えた。
路面のアルベドは不変。壁には白い細帯（幅 0.1 m、厚み 0.04 m、albedo 0.85）を 1.2 m 間隔で追加。
`calib_p2_wall.png`（全景）と `calib_p2_wall_closeup.png`（右側の日陰の壁を 4 倍）。

| 壁アルベド | 日陰の壁の見え方 | 白帯 | 全体 p50 |
| --- | --- | --- | --- |
| 0.18（従来） | ほぼ黒。藍と判別できない | 青灰の線として辛うじて見える | 15.7 |
| 0.35 | 暗い藍として読める最小値。線の間の面が判別できる | 読める | 15.7 |
| **0.50** | 藍がはっきり。参考画像の壁に近い | 線と面のコントラストが出る | 20.3 |
| 0.65 | 明るすぎ。壁が路面より目立つ。日の当たる壁は白飛び | 埋もれ気味 | 30.0 |

**推奨 0.50。最小 0.35。** 従来の 0.18 は「光の設定」の問題ではなく素材の問題だった、という見立ては正しい。

白帯について。日陰の中で線としては読めるが、色は**白ではなく薄い青**になる
（albedo 0.85 × 青い環境光）。参考画像の白線は日陰でも L≈218 で白い。
参考画像の日陰の壁は、路面の影の芯（11）の 20 倍の光を受けている計算になる。
これは A-3 の「影の階調」と同じ話で、壁面は路面の影の芯よりずっと多くの空の光を受けているはず、
という参考画像の照明モデルを、一様な環境光では再現できない。
壁のアルベドを上げても白帯の白さは戻らない（環境光の色で決まる）。

副作用: アルベド 0.50 では**日の当たる壁面が白飛びする**（右側の建物の側面、L 230 超）。
参考画像には日の当たる壁面が写っていない構図なので比較対象が無い。
太陽の方位を正面（`sun_az=185`）にすると日の当たる面が画面から消えるが、影の向きも変わる。構図の判断。

## 残る差（優先順）

1. **影の中の階調**（A-3）。参考の影は芯 11 と開けた影 30 の 2 段。こちらは一様に 13.5。
   中央値 20 対 40、L<20 面積 55% 対 25% の差はすべてここから来る。SSAO 大半径 / SDFGI の評価が次。
2. **日の当たる壁面の白飛び**（A-4 副作用）。構図（太陽方位）か、壁の日向側だけ抑える手当が要る。
3. 明部の彩度（0.24 対 0.17）。太陽の色をもう一段白く（(1.0, 0.88, 0.78) 程度）すれば下がる見込み。
   sun_energy 不変の縛りの外なので今回は触っていない。
