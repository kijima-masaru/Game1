## 生態系ごとの建物セット流用

| 生態系 | 商店街セットの流用 |
|---|---|
| `old_shopping_street` (F05) | — 基準 |
| `roadside_commercial` (F01) | 一部。大型店の記号（看板・自動ドア・陸屋根）が追加で要る |
| `suburban_residential` (F02) / `housing_estate` (F12) / `newtown_residential` (F13) | 可。屋根と塀の差し替えで対応 |
| `civic_plaza` (F06) / `school_dungeon` (F11) | 一部。鉄筋コンクリートの箱は流用可 |
| `temple_precinct` (F07) / `hilltop_shrine` (F08) / `paddy_shrine` (F14) / `forbidden_valley_temple` (F16) | 不可。社寺建築は別セット |
| `castle_ruins` (F09) | 不可。建物ではなく地形 |
| `orchard_valley` (F04) / `riverside_ground` (F10) / `riverbank_bridge` (F15) / `highway_underpass` (F03) | 不可。それぞれ固有 |
