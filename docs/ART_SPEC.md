# 素材制作仕様（ART_SPEC）

lookdev（2026-09-06、フェーズ 1〜4）で確定した、3D 背景 + ドット絵スプライト方式の素材制作ルール。
以降の素材はすべてこれに従う。根拠は docs/lookdev/ の各報告（REPORT / CALIBRATION / PHASE3 / PHASE4）。
検証シーンは `godot --path . res://scenes/lookdev.tscn`（既定値がこの仕様そのもの）。

## 1. スケールと基準面

| 項目 | 値 |
| --- | --- |
| texel 密度 | **28 texel/m**（世界テクスチャ・スプライトとも。`base_texel_per_meter`） |
| Sprite3D.pixel_size | 1/28 = 0.0357 m |
| 基準面 | **画面中央の地面**（カメラの注視点。キャラクターの足元が乗る平面）。ここで 1 m = 28 px |
| 描画解像度 | **640×360** を **整数 2 倍**（1280×720）。MSAA / TAA / FXAA なし |
| 基準面の画面縦幅 | 360 / 28 = 12.86 m |

背景は上端と下端で見かけの倍率が変わる（下記カメラ参照）。スプライトは第 5 節のスナップで常に 1 texel = 1 px。

## 2. カメラ

| 項目 | 値 | 根拠 |
| --- | --- | --- |
| 投影 | 透視 | 正射影は奥行きが失われ、路面のちらつきも多い（C-2） |
| 縦 FOV | **18°** | 1 m の板が画面上端 24 px / 中央 28 px / 下端 32 px（実測、C-1）。12° は正射影と見分けがつかず、22° 以上は変動 1.43 倍超 |
| 俯角 | **42°** | |
| ヨー | **60°**（街路に対して斜め、街路が奥へ抜ける） | D-4 |
| 距離 | **40.6 m**（FOV と 28 texel/m から逆算） | |
| 影の描画距離 | カメラ距離 + 40 m | |
| DOF | **使わない** | ドット絵に光学ボケは掛けない（E-0b）。C-2 の初出値は DOF 有効で測っており訂正済み |

背景の見かけ倍率は上端 0.857 〜 下端 1.143。スプライトはこの範囲で常に等倍にスナップされる（第 5 節）ので、素材は等倍表示だけを前提にしてよい。

## 3. 世界テクスチャ（路面・壁・屋根）

- **ミップマップあり**（`TEXTURE_FILTER_NEAREST_WITH_MIPMAPS`）。Nearest 単体はパン時のちらつきが 1.4 倍、
  昼の路面に波状モアレが出る（C-2 / C-3）。粒の質感は遠景で失われるが、ちらつきと引き換えに許容する。
- **繰り返しパターンの周期は 6 texel 以上。** 俯角 42° で地面は画面縦方向に sin 42° = 0.67 倍に圧縮され、
  28 texel/m の地面は画面上で縦 18.8 px/m にしかならない。C-3 で屋根の 4 texel 周期の瓦がエイリアスの帯になった。
- 三平面マッピング（ワールド座標）で貼るので、テクスチャの 1 タイルは m 単位で設計する（例: 32 texel = 1.14 m）。
- **壁のアルベド 0.50**（リニア輝度。日陰で「暗い藍」として読める最小は 0.35。0.65 は日向で白飛び）。
- 路面のアルベドは現行値（(0.42, 0.39, 0.47) の粒、およそ 0.15〜0.2）を基準にする。影の明度比の基準が路面なので変えない。
- 8 月の草・土は灰緑〜黄褐色だが、**彩度は路面と同程度に抑える**。オリーブ色の面は明部の色相・彩度統計を汚した（E-0c）。

## 4. 白い線・光る要素

- **白い線（窓枠・看板・白線・サイディングの横線）と光る要素（自販機のパネル・街灯・窓明かり）は
  unshaded または emission 板で作る。** 参考画像の白線は日向でも日陰でも L 170〜224 で、照明を受けていない（D-0）。
  拡散反射では影の中の白は L 35 が上限で、参考画像の見え方にならない。
- Glow を効かせたい発光体は **emission ×4〜8**。Sprite3D の modulate は 8bit で HDR にならず、
  UNSHADED マテリアルは emission を無視するので、`StandardMaterial3D`（通常シェーディング、albedo 黒、emission）の
  QuadMesh を重ねる（`_add_emissive` の構成）。

## 5. スプライト（ビルボード）

- 正面〜側面視、**カメラ正対のビルボード**（Y 軸回転のみだと俯角ぶん縦に潰れて行が欠ける）。足元を pivot に置く。
- `alpha_cut = DISCARD` で影を落とす。
- **フィルタ: Nearest。スケール: 見かけの texel/px 比を最も近い整数に丸める（E-3b 条件 C）。**
  FOV 18° の範囲（0.86〜1.14）では丸めると常に 1 倍、つまりスプライトは**距離に依らず等倍**で描かれる。
  奥行きによる大小の変化は捨てる（背景の透視はそのまま）。判断の根拠は PHASE4.md E-3。
  - 却下 A（Nearest そのまま）: 基準面から離れると 28 行のうち最大 4 行が不規則に間引き/重複され、歩くたびに入れ替わる
  - 却下 B（線形 + ミップマップ）: 間引きは消えるが縞が滲み、市松が灰色に溶ける。ドット絵でなくなる
  - 任意 D（C + 足元の画面位置を整数 px にスナップ）: ピクセルパーフェクトになるが、背景は滑らかに流れるので相対的な段付きが出る。要る場面だけ
- 実装: 毎フレーム見かけの比 `ratio = h_px / 28`（カメラ正対の 1 m の px 数 / 28）を求め、`scale = max(1, round(ratio)) / ratio` を Sprite3D に掛ける（`_walk_snap_scale`）。**下限 1 は必須**: 比が 0.5 を下回ると round が 0 になりスプライトが消える（カットシーンでカメラを引く場合に踏む）。
- 密度は世界と同じ 28 texel/m。キャラクター 1.7 m ≒ 48 texel。既存の PixelLab 素材（64 px 中 約 50 px ≒ 28 px/m）はそのまま使える。
- ノーマルマップ（`_n` / `_s`）は Sprite3D では使えない。使うなら QuadMesh + StandardMaterial3D。

## 6. メッシュ

- 建物は壁 4 面 + 天面の板で作り、**UV2 を持たせて AO を焼く**（`ao_on_uv2 = true`、`ao_light_affect = 0`、
  環境光にのみ効く）。レイ距離は建物高さの 2〜3 倍（18 m）。
- ただし **AO で作れる影の階調は小さい**（7 m 幅の街路・7 m の建物では路面の AO は 0.54〜0.71 の範囲、E-2c）。
  参考画像の「芯 ≈11 / 開けた影 ≈30」は照明の階調ではなく、路面テクスチャのアルベド分散（砂利とコンクリート）である可能性が高い（E-2a/E-2c）。素材が入れば解決する種類の差。
  **暗い芯が要る場所は、アルベド（路面の暗いパッチ）か、影を落とす物で作る。** AO に期待しない。
- 地面も UV2 付きの板。

## 7. ライティングの既定（夕方）

| 項目 | 値 |
| --- | --- |
| 太陽 | 高度 13°、方位はカメラ正面から左 15°（逆光。見える壁面はすべて日陰）、色 (0.905, 0.833, 0.815)、energy 4.2 |
| 環境光 | (0.327, 0.345, 0.429) × 0.386（AO 込みで路面の影の芯 / 日向 = 0.12） |
| 影 | 硬い（blur 0）、PSSM 2 分割、解像度 1024 で十分。**影アトラスは 32 bit 深度、bias 0.05、normal bias 4.0**（16 bit + 1.5 では昼にシャドウアクネの波状モアレが出る） |
| トーンマップ | **Filmic、white 1.0、露出 1.15**（Reinhard は white 1.0 で恒等写像なので比較に使わない） |
| Fog / Glow / SSAO / SSIL / SDFGI | OFF（Glow は発光体を置く場面で個別に ON） |
| 街灯 | 夕方は OFF。夜のみ ON |

太陽・環境光の色は「暖色の光 × 寒色の影」を保ちつつ低彩度（最終既定で明部彩度 0.15、暗部 0.51。参考 0.17 / 0.43）。
彩度の高い色は光源（emission 板）にだけ許す。

## 8. 測り方

- 明度は sRGB の Rec.709 輝度（0〜255）。参考画像の実測値と同じ定義（`tools/measure.py`）。
- 影の明度比は路面上の「日向の芯 / 影の芯」を **点**（3×3 平均）で測る。画面全体のパーセンタイルは使わない。
- パン時のちらつきは隣接フレームの MAD。絶対値はパン経路依存なので条件間の相対比較のみ。
- ヒストグラム・日陰面積率は記録するが目標にしない（素材の画素ばらつきが無い限り一致しない）。

## 9. 未決事項（決着済みとして閉じないこと）

1. **DOF。** 既定は OFF。ただし参考画像には DOF が入っており（左下手前がボケている）、過去作は意図的に使っていた。
   演出として再検討の余地がある。再検討する際は、**シマー測定を必ず DOF OFF で行った上で**判断すること
   （フェーズ 4 E-0 で、DOF がちらつきを 2.4 倍隠していたことが分かっている）。
2. **パレット。** 3D ライティングを通すため最終画面の色数は事実上無制限で、PixelLab の 76 色パレットは最終画面を
   拘束しない。「素材アルベドをパレットに拘束するか」「最終画面に色数量子化を掛けるか」は未決。当面どちらも行わない。
3. **確認項目。** スプライト等倍固定（第 5 節 C 案）により、画面上端と下端でキャラクターと周囲のサイズ関係が
   最大 17% ずれる（背景 0.857〜1.143 に対しスプライト 1.0）。縦切りで実物のスプライトをドア・自販機・車の横に
   立たせて確認すること。
